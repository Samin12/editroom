# /editroom:edit

Get this edited: **$ARGUMENTS**

Load the `edit-video` skill from this plugin and follow it end to end. Studio mode is the default:
ingest, cuts + privacy + proof research in parallel, section planning, briefs and section films (designer and
checker loops, pipelined per slot), continuity, wiring, render, final QA, import into a new Borumi project, and
a report with the video path, the chapters block and any flags. Use draft mode only if the arguments ask for a
quick draft or preview. Do everything without stopping unless the project can't be identified. Never upload or
publish.
